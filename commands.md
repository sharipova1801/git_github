### Команды Git
- `git init` — создание локального репозитория (создаётся скрытый файл .git);
- `git branch` — проверка названия ветки;
- `git clone` — клонирование удалённого репозитория (скачивает проект на компьютер);
- `git pull` — подтягивает свежие изменения проекта с сервера на копьютер;  
- `git status` — проверка статуса (покажет, какие файлы изменены);
- `git add .` — добавление файлов для отслеживания в локальный репозиторий; 
- `git add имя_файла.формат` — добавление отдельного файла для отслеживания локальный репозиторий;
- `git commit -m "комментарий"` — запись изменений в локальном репозитории (фиксирование изменений);  
- `git push` — отправка изменений из локального репозитория в удалённый;  
- `git branch` — создание новых веток;   
- `git checkout` — переключение между ветками;  
- `git merge` — объединение изменений (слияние веток);  
- `get reset` — возврат к предыдущей версии;  
- `git remote -v` — покажет адреса репозитория, к которому уже подключён проект; 
- `git remote set-url origin https://github.com/sharipova1801/git-github.git` — переподключение репозитория.  

**git push** — отправляет изменения на GitHub.  
**git pull** — забирает изменения с GitHub на компьютер.
