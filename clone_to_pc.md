### Как клонировать проект на компьютер
1. В GitHub на странице репозитория нажать зелёную кнопку **Code**.  
2. GitHub покажет готовую ссылку HTTPS для клонирования, например: 
`https://github.com/sharipova1801/test.git`  
3. Скопировать ссылку, нажав на **Copy URL to clipboard**
4. В терминале перейти в папку, в которую нужно скопировать проект `cd имя_папки`  
5. Клонировать (скачать) проект на компьютер 
`git clone https://github.com/sharipova1801/test.git`
