### Как связать локальную папку и удалённый репозиторий
Задача — превратить папку с проектом в локальный репозиторий и связать её с GitHub.  
1. В терминале перейти в папку репозитория (проекта):  
 `cd папка_проекта`
2. Инициализировать проект (превратить обычную папку в git-проект):  
`git init`
3. Подготовить файлы к сохранению (коммиту):  
`git add .`
4. Сохранить файлы в локальном репозитории:  
`git commit -m "Комментарий"`
5. Создать репозиторий на GitHub.
6. На странице созданного репозитория скопировать HTTPS адрес, например: 
`https://github.com/sharipova1801/test-test.git`  
7. Через терминал связать локальный репозиторий с удалённым:  
`git remote add origin https://github.com/sharipova1801/test-test.git`  
(origin — это стандартное имя для основного удалённого репозитория) 
8. Проверить, что связь добавилась:  
`git remote -v`  
Ожидаемый результат: строки с URL напротив **fetch** и **push**.
9. Отправить закомиченные файлы на GitHub:  
`git push -u origin master`  
Флаг -u irigin master нужен один раз: он связывает локальную ветку с удалённой.
