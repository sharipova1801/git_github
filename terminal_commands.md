### Базовые команды для работы в терминале
- `pwd` — узнать, где я;
- `cd имя_папки` — переход в папку имя_папки;  
- `cd ..` — вернуться на шаг назад (в предыдущую папку); 
- `ls` — список файлов и папок в текущем месте;
- `ls -la` — подробный список файлов и папок в текущем месте;  
- `mkdir имя_папки` — создание новой папки;  
- `del имя_файла` — удалить файл;  
- `rmdir имя_папки` — удалить папку;  
- `move файл папка` — переместить файл в папку;  
- `ctrl + C` — остановить.
