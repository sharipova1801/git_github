### Ветки
- Создание новой ветки:  
`git branch имя_новой_ветки`
- Создать ветку и сразу перейти в неё:  
`git checkout -b имя_новой_ветки`
- Отправить ветку на GitHub:  
`git push -u origin имя_ветки`  

### Как создать fork (скопировать чужой проект в свой репозиторий)
1. Перейти на страницу оригинального репозитория.
2. В правом интерфейсе страницы нажать **Fork**.
3. Выбрать аккаунт, куда скопируется проект.
4. Заполнить имя и описание. 
5. Выбрать ветку — главную или все.
6. Ждать завершение процесса. 

### Как создать новую ветку в GitHub (в форке)
1. Открыть Fork репозитория в GitHub.
2. В левой части интерфейса нажать **main**.
3. В текстовое поле ввести имя новой ветки.
4. Нажать **Create branch имя_новой_ветки from main**
5. Произойдет автоматический переход на новую ветку.
