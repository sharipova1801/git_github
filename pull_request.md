### Как создать Pull Request (запрос на слияние)
После commit (сохранения) нужно отправить изменения в общий репозиторий: 
1. Открыть Fork репозитория.
2. На главной странице репозитория нажать **Contribute**, затем **Open pull request**.
3. На открывшейся странице проверить, что сравниваются две ветки: моя (fork) и оригинальная. 
4. Заполнить заголовок и описание.
5. Нажать **Create pull request**.
